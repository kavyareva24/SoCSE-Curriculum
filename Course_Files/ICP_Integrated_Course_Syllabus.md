## Course Overview

This course is designed to introduce first-year B.Tech students to the foundational concepts of computer programming using the C language. It begins with an orientation to basic operating system usage (Unix and Windows) and version controlling in GitHub. The course then guides students through essential C programming constructs such as variables, data types, input/output functions, and control flow statements. Students will also be introduced to modular programming through user-defined functions. Emphasis is placed on understanding how to represent and manipulate data using arrays, strings, and structures. Through activity-based learning approach and guided practice, the course aims to build a strong foundation in computational thinking and structured programming essential for problem-solving in engineering contexts.

---

## Course Objectives

The objectives of this course are:

1. To familiarize students with basic Unix and Windows operating system commands essential for creating, compiling, debugging, and executing C programs and manage repositories in GitHub.
2. To develop an understanding of foundational C programming concepts such as variables, data types, and input/output operations.
3. To cultivate the ability to design modular programs using user-defined functions for efficient problem-solving.
4. To enable students to apply conditional and looping control flow constructs for solving illustrative problems.
5. To build proficiency in handling data through arrays, strings, and structures in C.

## Course Content

### Unit 1: Unix and Windows Commands & Version Control
Installation of required software. Commands for setting path variables, creating directory, changing working directory, copying files, deleting files. GitHub commands for create, fork, commit, pull and merge.

### Unit 2: Introduction to C Programming Constructs
Overview of C programming language and structure of a C program. Variables, expressions, operators, data types, input and output functions.

### Unit 3: Modular Programming with Functions
Concept of modularity and need for functions, User-defined functions: function declaration, definition, and call. Function arguments and return values (call by value).

### Unit 4: Control Flow in C, Arrays, Strings and Structures
- **Control Flow in C:** Conditional control statements: `if`, `if-else`, `else-if` ladder and `switch` case. Looping statements: `for`, nested loops, `while` and `do-while`. Unconditional Statements: `continue`, `return`, and `break`.
- **Arrays, Strings and Structures:** One and two-dimensional arrays. String handling in C: character arrays, usage of standard library functions. Structures: definition, declaration, and accessing members.

### CIE Assessment Protocol

The course utilizes a continuous, activity-based evaluation model facilitated through the **Moodle** platform, which eliminates traditional IA exams in favor of weekly proficiency tracking. The assessment follows these specifications:

#### Practical Evaluation
Students are required to execute **three programs** during each weekly lab evaluation on the Moodle platform:
- **Program 1:** The primary program taught during the previous week's theory session.
- **Program 2:** A program of comparable complexity that assesses the same concepts and programming constructs as Program 1. This program will be provided to students in advance to facilitate self-directed learning and practice. It will not be demonstrated or discussed by the faculty during the theory session, and students are expected to independently develop, practice, and master the solution before the evaluation.
- **Program 3:** The primary program from an earlier week (selected from the previously taught main programs) to reinforce long-term retention and evaluate sustained programming proficiency.

#### Integrated Theory Testing
For the primary program executed, a set of **10 Multiple Choice Questions (MCQs)** is dynamically generated from a pool of standardized questions to assess underlying conceptual knowledge on the Moodle platform.

#### Component Mapping
- **Theory Component:** Performance in the MCQ sets constitutes the marks for the Theory component of the CIE.
- **Lab Component:** Program execution and logic implementation constitute the marks for the Practical/Lab component of the CIE.

|---|:---:|:---:|:---:|

| Lab | # Programs | Marks per Program | Total Marks | Duration |
|---|:---:|:---:|:---:|

### Minimum Proficiency Requirement

To successfully clear the course, a student must satisfy the following cumulative and component-specific thresholds:

1. **Aggregate Passing Mark:** A student must achieve a cumulative minimum of **40 marks out of 100** across all components (CIE + SEE).
2. **SEE Threshold:** Out of the 40 Aggregate Passing Marks, a minimum of **20 marks** must be scored specifically within the SEE components (Theory SEE + Lab SEE).
3. **SEE Component Minimums:**
   - **Theory SEE:** Minimum **10 marks out of 25**.
   - **Lab SEE:** Successful execution of a minimum of **2 programs**.
