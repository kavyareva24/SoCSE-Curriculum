**COURSE OVERVIEW:**

This course is designed to introduce first-year B.Tech students to the foundational concepts of computer programming using the C language. It begins with an orientation to basic operating system usage (Unix and Windows) and version controlling in GitHub. The course then guides students through essential C programming constructs such as variables, data types, input/output functions, and control flow statements. Students will also be introduced to modular programming through user-defined functions. Emphasis is placed on understanding how to represent and manipulate data using arrays, strings, and structures. Through activity-based learning approach and guided practice, the course aims to build a strong foundation in computational thinking and structured programming essential for problem-solving in engineering contexts.

**COURSE OBJECTIVES:**

The objectives of this course are:

- To familiarize students with basic Unix and Windows operating system commands essential for creating, compiling, debugging, and executing C programs and manage repositories in GitHub.
- To develop an understanding of foundational C programming concepts such as variables, data types, and input/output operations.
- To cultivate the ability to design modular programs using user-defined for efficient problem-solving.
- To enable students to apply conditional and looping control flow constructs for solving illustrative problems.
- To build proficiency in handling data through arrays, strings, and structures in C.

#### COURSE CONTENT

**Unit - 1**

**Unix and windows Commands:** Installation of required software. Commands for setting path variables, creating directory, changing working directory, copying files, deleting files. GitHub commands for create, fork, commit, pull and merge.

**Unit - 2**

**Introduction to C Programming Constructs:** Overview of C programming language and structure of a C program. Variables, expressions, operators, data types, input and output functions.

**Unit - 3**

**Modular Programming with Functions:** Concept of modularity and need for functions, User-defined functions: function declaration, definition, and call. Function arguments and return values (call by value).

**Unit - 4**

**Control Flow in C:** Conditional control statements: if, if-else, else-if ladder and switch case. Looping statements: for, nested loops, while and do-while. Unconditional Statements: continue, return, and break.

**Arrays, Strings and Structures:** One and two-dimensional arrays. String handling in C: character arrays, usage of standard library functions. **Structures:** definition, declaration, and accessing members.
