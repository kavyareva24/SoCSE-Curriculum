## Course overview

This course prepares students to become proficient Salesforce-based Cloud Data Administrators. Students gain practical experience on the Salesforce platform using Trailhead, focusing on user and data management, security configurations, UI customization, reporting, and workflow automation. Emphasis is placed on real-time business scenarios through hands-on exercises and a capstone project.

## Course objectives

- Understand the core architecture and components of the Salesforce platform relevant to administrators.
- Configure and manage user access, security settings, profiles, and permission sets.
- Model and customize data structures using standard and custom objects, Schema Builder, and validation rules.
- Build and manage reports, dashboards, and data visualizations to support business intelligence.
- Customize user interfaces using Lightning App Builder, list views, and record pages.
- Apply automation tools such as workflows, flows, and approval processes to streamline business operations.

## Course content

### Unit 1 — Salesforce fundamentals and user management

- Overview of the Salesforce platform, architecture, and AppExchange
- Salesforce setup and customization for users
- Managing user roles, profiles, and access
- Identity basics and permission set groups
- Data security: organization-wide defaults, role hierarchy, sharing rules, login hours, IP restrictions, and field-level security

#### Suggested activities
1. Create a Salesforce Developer Edition org and explore the Setup menu, navigation, and standard objects.
2. Create sample user roles, profiles, and permission sets for a sales team and compare their access levels.
3. Configure organization-wide defaults, role hierarchy, and sharing rules for a simple sales scenario.
4. Practice applying login hours, IP restrictions, and field-level security for a test user.
5. Prepare a short report explaining the difference between profiles, roles, permission sets, and permission set groups.

### Unit 2 — Data modeling and UI customization

- Standard and custom objects
- Schema Builder and object relationships
- Picklists, formula fields, record types, validation rules, and field history tracking
- Lightning App Builder: home and record page customization
- Compact layouts, list views, quick actions, buttons, and links
- Lightning components and user-interface extensions

#### Suggested activities
1. Create standard and custom objects and define relationships using Schema Builder.
2. Build picklists, formula fields, and record types for a sample business object.
3. Add validation rules and field history tracking to enforce data quality.
4. Customize a Lightning record page using App Builder and add compact layouts, quick actions, and buttons.
5. Create and compare list views for different user roles in a business case.

### Unit 3 — Sales and Service Cloud with data management

- Managing accounts, contacts, leads, and opportunities
- Quotes, price books, contracts, and campaigns
- Sales Path and Kanban views
- Service Cloud Console setup
- Web chats, case automation, entitlements, queues, and escalation rules
- Importing and exporting data using Dataloader.io
- Duplicate management and record integrity

#### Suggested activities
1. Create and manage accounts, contacts, leads, and opportunities in a sample sales pipeline.
2. Configure quotes, price books, contracts, and campaigns for a product-based organization.
3. Set up Sales Path and Kanban views to track opportunities through the sales process.
4. Design a simple Service Cloud setup with cases, queues, entitlements, and escalation rules.
5. Import and export sample data using Data Loader.io and identify duplicate records.

### Unit 4 — Reports, dashboards, automation, and capstone project

- Report Builder: filters, summaries, grouping, and formulas
- Creating dashboards: folders, charts, and visualizations
- Approval processes and Flow Builder basics
- Record submission, notifications, and flow variables
- Trailhead capstone project: end-to-end Salesforce implementation
- Presentation and evaluation of project deliverables

#### Suggested activities
1. Build a summary report with filters, grouping, and formulas to analyze business data.
2. Create a dashboard with charts and visualizations for key sales or service metrics.
3. Design a simple approval process and a flow to automate record submission or notifications.
4. Implement a Trailhead-based capstone scenario and document the configuration steps taken.
5. Present the completed Salesforce solution and explain the business value of the implemented features.
