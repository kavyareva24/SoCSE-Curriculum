**Pre-requisite:**

Digital Logic Design, Computer Organization and Architecture, Microprocessor, Programming in C.

**Overview of Course:**

This course introduces the architecture, programming, and design principles of Embedded Systems. It covers embedded hardware architectures, ARM-based microcontrollers, embedded software development tools, communication interfaces, real-time operating systems, and peripheral interfacing techniques. Students will gain knowledge of modern embedded system design using Embedded C and Python, industrial communication protocols, and real-time software development for applications in consumer electronics, industrial automation, automotive systems, healthcare, and Internet of Things (IoT).

**Course Objectives:**

**CO1**: Understand the fundamentals, architecture, characteristics, and quality attributes of embedded systems.

**CO2:** Develop Embedded C programs using ANSI C, GNU development tools, and cross-compilation techniques for embedded applications.

**CO3:** Analyze hardware–software co-design principles and computational models used in embedded system design.

**CO4:** Design embedded systems by interfacing GPIO with peripherals such as LED, Switch, LCD, 7-segment display, ADC, DAC, and stepper motor.

**CO5:** Explain RTOS concepts, processes, threads, scheduling algorithms, and real-time task management in embedded systems.

**CO6:** Apply embedded system design concepts to develop efficient and reliable real-time embedded applications using appropriate software and hardware techniques.

**Syllabus:**

| **Unit – 1** |
| **Typical Embedded Systems:** Core of the embedded system, memory, sensors and actuators, communication interface, other system components, characteristics and quality attributes of embedded systems. **Self learning:** ARM Cortex-M architecture. |
| **Unit – 2** |
| **Programming for Embedded Systems:** Overview of ANSI C, GNU development tools, bit manipulation using C, memory management, timing of programs, device drivers. Types of files generated on cross compilation, disassembler/decompiler, simulators and emulators. **Hardware Software Co-Design and Program Modelling:** Fundamental issues in hardware software co-design, computational models in embedded systems **Self learning:** System-on-Chip (SoC) Architecture and Applications |
| **Unit – 3** |
| **GPIO and Interfacing: General purpose input/output ports, Interfacing of** LED, Switch, LCD, 7-segment, stepper motor, ADC, and DAC . **Self learning:** SPI protocol. |
| **Unit – 4** |
| **RTOS and IDE for Embedded System Design:** Operating system basics, types of operating systems, tasks, Processes, Signals, process and threads, Multithreading, Multiprocessing and Multitasking, Task Scheduling: Scheduling Algorithms-Non Preemptive Scheduling, preemptive scheduling with numerical. **Self learning:** Free RTOS. |
